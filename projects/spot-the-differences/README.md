# Game Cari Perbedaan Radar

Selamat datang di Game Cari Perbedaan Radar! 🎮🔍

Ini adalah permainan interaktif berbasis web yang menantang pemain untuk menemukan perbedaan antara dua radar yang tampak identik. Permainan ini menggunakan elemen canvas HTML5 untuk membuat visualisasi radar yang dinamis dan menarik.

## 🎯 Cara Bermain

1. Masukkan nama Anda untuk memulai permainan
2. Perhatikan dua radar yang ditampilkan - radar kiri dan radar kanan
3. Temukan perbedaan antara keduanya (partikel dengan warna berbeda)
4. Tebak di zona mana perbedaan tersebut berada (zona 1-12)
5. Lihat apakah tebakan Anda benar dan kumpulkan poin!

## 🌟 Fitur

- **Visualisasi Radar Dinamis**: Menggunakan canvas HTML5 untuk membuat efek radar yang realistis
- **Sistem Skor**: Lacak kemenangan dan jumlah permainan yang dimainkan
- **Leaderboard**: Lihat peringkat pemain berdasarkan jumlah kemenangan
- **Desain Responsif**: Dapat dimainkan di berbagai perangkat
- **Penyimpanan Lokal**: Data pemain disimpan di browser Anda

## 📁 Struktur Proyek

```
game_cari_perbedaan/
├── index.html          # Halaman utama permainan
├── style.css           # Gaya dan tampilan permainan
├── script.js           # Logika permainan

```

## 🎮 Teknologi yang Digunakan

- HTML5 Canvas untuk visualisasi radar
- CSS3 untuk desain dan animasi
- JavaScript ES6 untuk logika permainan
- LocalStorage untuk penyimpanan data pemain

## ▶️ Cara Menjalankan

1. Clone repositori ini atau unduh file ZIP
2. Buka file `index.html` di browser Anda
3. Masukkan nama Anda dan mulai bermain!

Atau kunjungi [tautan GitHub Pages] untuk bermain langsung!
