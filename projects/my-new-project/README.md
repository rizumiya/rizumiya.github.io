# Proyek Baru Saya

Contoh proyek web interaktif yang dibuat untuk menunjukkan struktur proyek di Hexo blog.

## Deskripsi

Proyek ini menunjukkan cara membuat proyek web yang terintegrasi dengan Hexo static site generator. Proyek ini disimpan di folder `source/projects/` sehingga akan diproses dan dipublikasikan sebagai bagian dari situs GitHub Pages.

## Fitur

- Desain responsif
- Antarmuka yang menarik
- Kode yang terorganisir
- Interaktivitas sederhana

## Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript
- Hexo (sebagai static site generator)

## Cara Menjalankan

Proyek ini adalah proyek web statis yang dapat diakses langsung melalui browser. Setelah proses build Hexo selesai, proyek akan tersedia di URL:
`https://rizumiya.github.io/projects/my-new-project/`
